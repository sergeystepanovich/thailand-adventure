📱 Как установить и запустить
🍎 iPhone — Safari:
1Скачай файл игры (.html)
2Открой приложение «Файлы», найди файл
3Нажми на файл — откроется в Safari
4Нажми кнопку «Поделиться» (квадрат со стрелкой ↑) внизу
5Выбери «На экран "Домой"» → «Добавить»
6Готово! Иконка появится на главном экране 🎮
🤖 Android — Chrome:
1Открой файл в Chrome
2Меню (три точки) → «Добавить на главный экран»
👥 Играть вдвоём:
Отправь файл другу через Telegram / AirDrop. Он открывает игру → нажимает «Играть вдвоём» → вводит тот же код комнаты что и ты!
🌐 Совместная игра
Создай комнату → отправь код другу
Он вводит тот же код и нажимает «Войти»
